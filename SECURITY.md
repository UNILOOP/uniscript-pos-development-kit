# Security reporting

Do not publish credentials, clinical data or exploit details in a public issue. Report vulnerabilities privately through the UniScript team or the repository's private vulnerability reporting facility once configured. There is no invented security contact address in this local preparation.

The workbench is local-only trusted tooling. Do not expose its HTTP port or Docker socket publicly. Package code must remain inside the isolated runtime; package UI must remain on its isolated origin with host reauthorization. A source ZIP never grants new endpoint, credential, tenant or payment authority.
