# Contributing

Start with the README quickstart and tests. Keep the developer host vendor neutral; use fixtures or adapters for vendor behavior. Add meaningful positive and negative coverage for contract changes. Keep dependencies within the documented supported profile and preserve container, origin, scope and revision boundaries.

Update public contracts, compiled bridge copies, examples, documentation and host conformance together. Do not add private UniScript source or infrastructure data. Use synthetic data only. MIT contributions must be compatible with this repository's license.

Before sharing a package, run archive/export checks, isolated runtime tests and browser workflows. Report exactly which checks were run and whether a result was simulated, real local execution or external sandbox behavior.
